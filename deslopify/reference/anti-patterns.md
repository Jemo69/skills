# AI Slop Anti-Patterns Catalog

This catalog documents the recurring speculative patterns generated by AI models in web, mobile, and backend applications, along with their production remedies.

---

### 1. The 10-Slider Canvas Trap
* **Symptoms**: Sliders for coordinates, card padding, border radiuses, element width, and zoom percentages crammed into an editor, paired with fragile mouse-drag collision math.
* **Why AI Does It**: AI models hallucinate that every card, preview, or visual component needs to be a complex standalone graphic editor.
* **Failure Mode**: Jittery drag interactions, text clipped outside container boundaries, and broken layout resets across screen sizes.
* **Remedy**: Delete the manual drag math and granular sliders. Replace with:
  - Curated, beautifully proportioned presets.
  - Deterministic responsive layout.
  - Progressive disclosure accordions for high-level styles rather than raw coordinates.

---

### 2. The Multi-Tab Guessing Game
* **Symptoms**: Multiple separate tabs or segmented controls for "Search by ID", "Search by Email", "Search by Name", "Search by Phone".
* **Why AI Does It**: Over-engineering backend query parameters directly into the top-level user interface.
* **Failure Mode**: Users enter input into the wrong tab and receive confusing "Record not found" errors.
* **Remedy**: Consolidate into a **single smart input field**:
  - Automatically detect the input type via simple pattern recognition or heuristics.
  - Submit the appropriate query behind the scenes with zero user cognitive friction.

---

### 3. The Doorway Blocker (The Blocking Tax)
* **Symptoms**: Full-screen modal overlays, confirmation dialogs with OK buttons, or multi-second animated spinners on high-frequency repetitive tasks (e.g., scanning items, batch status updates, quick entry, checkout).
* **Why AI Does It**: Treating every mutation as a dramatic, isolated event requiring explicit user acknowledgment.
* **Failure Mode**: High-frequency workflows stall; users must tap "Dismiss" or wait on animations between every single action.
* **Remedy**:
  - Replace blocking modals with **floating toast notifications** that auto-dismiss quickly.
  - Allow immediate subsequent actions without waiting for notifications to fade.
  - Use subtle non-blocking status cues instead of modal walls.

---

### 4. The Ghost Metric Card
* **Symptoms**: Sleek dashboard cards displaying cosmetic storage, system health, or quota gauges with static hardcoded numbers.
* **Why AI Does It**: Inserting visual dashboard filler from training data mockups without backing database schema or infrastructure telemetry.
* **Failure Mode**: Users panic over fake limits or trust health indicators that never update during an actual outage.
* **Remedy**:
  - Check if real backend metrics or APIs exist.
  - If they do not exist, delete the card completely. Never ship cosmetic metrics.

---

### 5. The Sci-Fi Radar Aesthetic
* **Symptoms**: Neon glows, excessive box-shadows, pulsing radar dots, and unreadable stylized fonts on business dashboards and public result screens.
* **Why AI Does It**: An inclination toward flashy tech-demo styling rather than legible editorial tools.
* **Failure Mode**: Elements are unreadable under daylight, washed out on external displays, or illegible from a distance.
* **Remedy**:
  - High-contrast, accessible color tokens.
  - Clean typography with generous scale ratios.
  - High legibility on shared displays.

---

### 6. The Premature Data Leak
* **Symptoms**: Displaying live voting percentages, aggregate feedback totals, or answers to users *before* they have submitted their own response.
* **Why AI Does It**: Reusing public query endpoints across both public intake interfaces and administrative views without role checks.
* **Failure Mode**: Users look at the current front-runner or answers, causing bandwagon bias or biased data.
* **Remedy**:
  - Guard results until the user has submitted their response, or restrict live displays to dedicated presentation/admin screens.

---

### 7. The Competing Creation Buttons
* **Symptoms**: A header row displaying separate creation buttons for every minor subtype or variation of an entity.
* **Why AI Does It**: Generating duplicate UI affordances for every minor variant of a database record.
* **Failure Mode**: Visual clutter and user hesitation over which button to press.
* **Remedy**:
  - Consolidate into a single prominent primary creation button.
  - Let the user select the subtype inside the creation modal via a clean segmented toggle.

---

### 8. The Orphan Media / File Browser
* **Symptoms**: A detached file explorer tab allowing users to upload arbitrary files with no connection to actual entities, records, or fields.
* **Why AI Does It**: Boilerplate scaffolding assuming every application needs a generic cloud storage file explorer.
* **Failure Mode**: Uploaded files sit idle in storage, serving no purpose in the actual product workflow.
* **Remedy**:
  - Delete the detached file browser.
  - Attach file uploads directly where they are consumed.
